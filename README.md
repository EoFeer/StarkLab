### <h1>StarkLab 👨‍💻🚀🦾</h1>
<br>

<h2>StarkLab é um projeto web desenvolvido com HTML, CSS e JavaScript, criado para apresentar e explorar as icônicas armaduras do Homem de Ferro.
<br>
<br>
Inspirado no universo Marvel e na genialidade de Tony Stark, o site funciona como uma galeria interativa das Marks, trazendo informações sobre cada armadura e seu propósito.</h2>
<br>

### ✨Funcionalidades

<ul>
  <li> <b>Galeria das Armaduras:</b> exibição das Marks com imagens em alta qualidade. </li>
  <li> <b>Botão Jarvis: </b> desenvolvido com auxílio de ChatGPT, adicionando uma camada interativa ao projeto. </li>
  <li> <b>Design Responsivo:</b> interface adaptada para diferentes dispositivos. </li>
</ul>
<br>

### 🎨Créditos de Imagens

As imagens das armaduras foram obtidas em <b>DeviantArt</b>, na página do criador <b>EliteRobo</b>, que disponibilizou os PNGs utilizados no projeto.

### 🚀Objetivo

O projeto tem como objetivo unir <b>programação front-end</b> e <b>cultura pop geek,</b> criando uma experiência visual e interativa que celebra o legado das armaduras de Tony Stark.
